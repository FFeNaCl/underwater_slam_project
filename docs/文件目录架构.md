## 0. 总览与数据流

```
相机(/dev/video*) 或 VRX 相机 或 合成播放器
        │  /image_raw (sensor_msgs/Image)
        ▼
image_enhancer_cpp (C++, enhancer)
   红通道补偿 -> Gray World 白平衡 -> CLAHE -> (标定后)去畸变
        │  /image_enhanced（可选 /image_enhanced_debug 对比图）
        ▼
检测（二选一，同一套 /detections JSON 契约）
 ├─ yolo_vrx_bridge (Python, ultralytics, models/best.onnx)  -> /yolo/annotated, /yolo/detections
 └─ underwater_perception cube_detector (Python, 颜色+几何)   -> /detections, /detections/annotated, /detections/markers
        │
        ▼
underwater_perception slam_input_bridge
        │  /mono_py_driver/img_msg + /mono_py_driver/timestep_msg（握手 /mono_py_driver/experiment_settings -> ACK）
        ▼
ros2_orb_slam3 mono_node_cpp（打补丁版 ORB-SLAM3 V1.0）
        │  /slam/pose(Twc) /slam/path /slam/map_points /slam/status /tf(map->camera)
        ▼
underwater_perception semantic_landmark（多视图三角化）
        │  /semantic/landmarks /semantic/markers
        ▼
RViz2（config/rviz/slam.rviz，Fixed Frame: map）+ rosbag 录制
```

### 7.4 underwater_perception/core/（纯算法层，**不 import rclpy**，可离线测试）

| 文件 | 作用 |
| --- | --- |
| `types.py` | `/detections` 消息契约 v1：DetectionFrame / Detection / GeometryMetrics / Measurement（method: none→bearing_only→known_size→known_size_pose→known_size_refined 信任度递增）+ IoU 工具。是 YOLO JSON 的超集 |
| `params.py` | **参数唯一事实来源**：全部 flat 参数 dataclass（Color/Detect/Track/Measure/CubeDetector/SlamBridge/Calibration/Landmark）+ HSV_PRESETS 7 色 + load_flat_yaml / declare_from_flat（ROS 参数映射，跳过嵌套 dict）。所有 key 名出自这里 |
| `colors.py` | HSV 掩码构建、red_dominance_mask（R>1.15G 且 R>1.15B，抑制白光与蓝绿背景）、形态学清理、掩码统计 |
| `cv_compat.py` | OpenCV 4/5 兼容层：findContours 参数差异、findChessboardCornersSB 回退经典版、solve_pnp_square 校验（深度>0 且重投影≤5 px，防 IPPE 退化解） |
| `cube_geometry.py` | **几何旁路核心**：HSV 掩码→轮廓→顶点数(4~6)/凸性/填充比/长宽比门限→内部棱线分析（Canny+HoughLinesP 方向聚类+Harris Y 节点）→加权打分→mode 门限（any/square_face/cube_silhouette）→NMS→可选测距。CubeDetector 门面加 IoU 跟踪。文件头如实列出局限（背光黑块/共面视角与正方形色块不可区分等） |
| `tracker.py` | 贪心 IoU 跟踪器（SORT-lite）：min_hits=2 确认、max_age=8 删除、多边形 IoU 关联 |
| `measurement.py` | 像素射线/方位角、known_size 测距（Z=f·L/s）、面位姿枚举 8 种角点顺序、**立方体中心修正**（可见面中心≠体心，±半边长歧义）、refine_cube_pose（PnP+ICP+多起点）、三角化（线性最小二乘+秩保护） |
| `landmarks.py` | LandmarkManager：按 track_id 累积观测→视差/基线过滤→三角化→重投影误差剔除；无位姿时 scale_fallback 模式；过期清理 |
| `calibration.py` | 标定全流程：detect_pattern（棋盘/圆/ChArUco）、validate_corners 单应网格校验（防错锁网格）、collect_views、calibrateCamera + 逐视图误差 + 覆盖/RMS 警告、undistort_image、**四件套输出写入器**（ost.yaml ROS 兼容、ORB-SLAM3 yaml 以 %YAML:1.0 开头、enhancer_camera_params.yaml、calibration_report.json） |
| `synthetic.py` | 合成数据生成：水下背景（蓝绿渐变+纹理+噪声+暗角）、透视立方体渲染（逐面着色+12 棱+真值轮廓）、立方体序列、带静区的棋盘格、15 视图板集 |
| `visualize.py` | annotate_detections（轮廓/顶点/标签含 track_id/置信度/距离）、mask_overlay、side_by_side、状态面板——节点与 CLI 共用，保证画面一致 |
