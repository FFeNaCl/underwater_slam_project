## 构建后路径

```bash
cd ~/underwater_slam_project
source /opt/ros/humble/setup.bash
colcon build
source install/setup.bash
```

ORB-SLAM3 的 Vocabulary 和 config 已通过 CMake 安装到
`install/ros2_orb_slam3/share/ros2_orb_slam3/orb_slam3/`，
因此 launch 使用包路径即可，不再依赖原来的 `~/orb_slam3_ws`。

## 运行前检查

```bash
# 相机稳定路径
ls -l /dev/v4l/by-id/

# 标定文件存在
ls config/orbslam3/water_1280x480.yaml

# 模型存在
ls models/best.pt models/best.onnx

# 只有一个 mapping 进程
ps -ef | grep -E "[m]apping.launch|[m]ono_node_cpp"
```

## 主要限制

- 单目 SLAM 输出稀疏地图，不是稠密三维重建；
- 地图无绝对米制尺度；
- 必须有平移才能初始化；
- 同一时间只能跑一套 mapping；
- 当前 YOLO 模型训练数据只有 13 张，精度仅供流程验证。
